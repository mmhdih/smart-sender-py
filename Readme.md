# 🚀 SmartSender (ارسال پیام گروهی هوشمند)

این اپلیکیشن یک ابزار دسکتاپ با رابط کاربری مدرن (طراحی شده با CustomTkinter) است که به شما اجازه می‌دهد پیام‌های متنی خود را به صورت گروهی و خودکار از طریق **واتس‌اپ** و **تلگرام** ارسال کنید.

## ✨ ویژگی‌ها
- 🎨 **رابط کاربری مدرن و زیبا:** طراحی مینیمال با پشتیبانی از حالت تاریک (Dark Mode).
- 💬 **پشتیبانی از واتس‌اپ و تلگرام:** ارسال پیام با استفاده از `pywhatkit` و `Telethon`.
- ⚡ **پردازش موازی (Threading):** جلوگیری از فریز شدن برنامه هنگام ارسال پیام‌ها.
- 📦 **نسخه پرتابل (Portable):** بیلد خودکار فایل `.exe` بدون نیاز به نصب از طریق GitHub Actions.

##  پیش‌نیازها
- Python 3.11 یا بالاتر
- حساب کاربری تلگرام (برای دریافت API)
- لاگین بودن در نسخه وب واتس‌اپ روی مرورگر پیش‌فرض سیستم
